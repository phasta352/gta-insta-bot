# Background music for Reels

Put licensed music files here (`.mp3`, `.m4a`, `.wav` or `.aac`) and the bot picks one at random for each Reel.

Only use tracks you have the right to use on social media, for example:
- Pixabay Music (free, commercial use allowed, check each track's licence)
- YouTube Audio Library (free; some tracks require a credit in the caption)
- Epidemic Sound or Artlist (paid subscriptions that cover commercial social media use)

Don't use popular songs: Instagram mutes or blocks them.

If this folder has no music files, the bot generates an original royalty-free track for each Reel.
